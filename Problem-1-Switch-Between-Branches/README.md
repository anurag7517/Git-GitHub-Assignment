\# Problem 1: Switch Between Branches



Problem ID: GIT-24



\## Objective

To create branches and switch between them using Git.



\## Procedure

1\. Created a Git repository.

2\. Created a file named branch-demo.txt on main.

3\. Created feature-branch.

4\. Switched to feature-branch using git switch.

5\. Modified the file and committed the changes.

6\. Switched back to main.

7\. Verified that the feature branch change was not present on main.



\## Commands



&#x20;   git branch feature-branch

&#x20;   git branch

&#x20;   git switch feature-branch

&#x20;   git add branch-demo.txt

&#x20;   git commit -m "Update file on feature branch"

&#x20;   git switch main

&#x20;   git branch



\## Result

Successfully created and switched between Git branches.

Verified that each branch maintains its own version of committed files.

# Git and GitHub Assignment

## Student Details
- Roll Number: 24
- Subject: Git and GitHub
- Platform: Git Bash and GitHub

## Objective
To understand Git branch switching and viewing commit history.

## Problem 1: Switch Between Branches (GIT-24)
Created a feature branch, switched between main and feature-branch,
and verified that changes remain isolated until merged.

## Problem 2: View Commit History (GIT-07)
Used Git commands to inspect commit history, commit messages,
and branch history.

## Commands Used
- git init -b main
- git branch
- git switch
- git add
- git commit
- git log --oneline
- git log --graph --oneline --all

## Tools
- Git Bash
- Git
- GitHub

## Conclusion
The assignment demonstrates basic Git branching and commit history
management using Git Bash and GitHub.

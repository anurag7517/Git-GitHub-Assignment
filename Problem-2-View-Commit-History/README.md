\# Problem 2: View Commit History



Problem ID: GIT-07



\## Objective

To view and understand the commit history of a Git repository.



\## Procedure

1\. Created commits on main and feature-branch.

2\. Used git log --oneline to view a concise commit history.

3\. Used git log to view detailed commit information.

4\. Used git log --graph --oneline --all to inspect branch history.



\## Commands



&#x20;   git log

&#x20;   git log --oneline

&#x20;   git log --graph --oneline --all



\## Result

Successfully viewed commit IDs, commit messages, author details,

dates, and branch history.
